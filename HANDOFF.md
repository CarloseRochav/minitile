## 1. What minitile is

A Python 3.12 learning project inspired by physical-aware floorplanning. From a YAML design
(die, rectangular modules, nets) it validates the input, places movable modules with greedy
placement plus simulated annealing, routes every net with grid A\*, and reports length,
Manhattan lower bound, detour ratio and pipeline stages as JSON, a rich table, and an SVG.

## 3. Code map

```
src/minitile/
  model.py      pydantic models: Die, Module, Net, Design, Placement, result types
  geometry.py   rect cells, overlap area, gap (Manhattan) distance, halo checks
  parser.py     YAML -> Design; collects ALL validation errors into one DesignError
  cost.py       full cost + incremental delta for move/swap (delta == full diff is tested)
  placer.py     greedy initial placement, simulated annealing, legality check
  router.py     multi-source grid A*, deterministic tie-breaking (f, h, x, y)
  metrics.py    per-net metrics + summary
  api.py        Floorplan API (immutable; place/route/report return new objects), to_json/to_svg
  render.py     stdlib-only SVG drawing (SPEC Section 14)
  cli.py        typer app: validate, run (--out, --svg), report, render
tests/          one test file per module + test_golden, test_properties, test_determinism
testcases/      example YAMLs + *.golden.json / *.golden.svg
scripts/benchmark.py   performance check (not part of CI)
docs/img/soc_demo.svg  README image (regenerated by --update-golden)
```

CLI exit codes for `run`: `0` ok, `1` invalid design, `2` illegal placement, `3` unroutable net.

## 4. How to work on it

```bash
uv sync
uv run pytest
uv run ruff check && uv run ruff format --check
uv run mypy --strict
uv run python scripts/benchmark.py
uv run pytest --update-golden   # ONLY when an output change is intended; review the diff
```

Rules that every change must keep (from CLAUDE.md and SPEC.md):

- SPEC.md formulas are the source of truth. If something is ambiguous or looks wrong, **ask the
  user** instead of guessing or changing a definition.
- Every step ends with tests, ruff, ruff format and `mypy --strict` clean, then **one commit**.
- No new dependencies beyond SPEC Section 2 without asking. Rendering is stdlib only.
- No global state. All randomness goes through one seeded `random.Random`.
- **Determinism is tested.** Same design + params + seed gives byte-identical JSON and SVG, also
  across different `PYTHONHASHSEED` values. Do not iterate over sets/dicts in an order that can
  change, and do not add timestamps or random ids to output.
- Goldens are never regenerated automatically. If a golden test fails, find out why before
  running `--update-golden`.

Deliberate interpretations of the spec (documented in README "Implementation notes"): symmetric
halo penalty `hv(a,b) + hv(b,a)`; duplicate nets merged for cost but routed separately;
overlapping footprints get route length 0; all-fixed designs skip placement
(`summary.placement_skipped = true`); greedy result is returned if annealing never improves it.

## 5. Gotchas

- **Windows / Git Bash:** `uv run pytest` and `uv run mypy` can fail with
  `uv trampoline failed to canonicalize script path`. Use `uv run python -m pytest` and
  `uv run python -m mypy --strict` instead.
- **Console encoding:** on cp1252 consoles the table prints `->`/`-` instead of `→`/`−`.
  Set `PYTHONIOENCODING=utf-8` for the Unicode glyphs. When piped, the table prints at natural
  width.
- `.gitattributes` forces LF; a test checks that goldens have LF line endings.
